# Farmkogls Booking Console — 공개 배포용 저장소

에이전트 주간 예보를 통합 등록부에 반영하고, 항차별 BSA 대비 선복을 확인하는
사내 도구입니다. **정적 페이지 하나**라서 서버도 데이터베이스도 없습니다.

| | |
|---|---|
| 사이트 진입 | `index.html` (저장소 루트) |
| PIN | 4자리 — `tool/build_site.py`의 `PIN` 상수 |
| 소스 | `tool/` |
| 빌드 | `python tool/build_site.py` → `tool/site/index.html` → 루트로 복사 |

---

## 이 저장소에 절대 넣지 않는 것

**실제 부킹 자료입니다.** `.gitignore`가 `*.xlsx` 전체와 `tool/testdata/`를 막고
있고, 배포 스크립트도 복사 단계에서 아예 집어 들지 않습니다.

한 번이라도 커밋되면 나중에 파일을 지워도 **과거 커밋에 영원히 남습니다.**
새 파일을 추가할 때 `git status`를 먼저 확인하세요.

이 도구 자체에는 부킹 자료가 들어 있지 않습니다. 사용자가 브라우저에서 자기
엑셀을 열 뿐이고, 그 내용은 **각자 PC를 벗어나지 않습니다.**

---

## 배포 (GitHub Pages)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 **Settings → Pages** 로 갑니다.
3. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 선택 → Save.
4. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

GitHub Pages 무료 플랜은 **공개 저장소**에서만 됩니다. 소스를 비공개로 두면서
사이트만 공개하려면 아래 "다른 호스팅"을 보세요.

### 자체 도메인을 쓰려면
`CNAME` 파일에 도메인 한 줄을 넣고, 도메인 DNS에서
`CNAME` 레코드를 `<사용자명>.github.io` 로 지정합니다.

---

## 다른 호스팅 (비공개 저장소 + 공개 사이트)

| 서비스 | 무료로 되나 | 설정 |
|---|---|---|
| **Cloudflare Pages** | 비공개 저장소 OK | 빌드 명령 없음, 출력 디렉터리 `/` |
| **Netlify** | 비공개 저장소 OK | Publish directory `/` |
| **Vercel** | 비공개 저장소 OK | Framework: Other, Output `/` |

셋 다 저장소에 push하면 자동으로 다시 배포합니다.

## PIN에 대해

**보안이 아니라 문고리입니다.** 검사가 브라우저 안에서 일어나므로,
소스를 볼 줄 아는 사람은 우회할 수 있습니다. 네 자리는 만 번이면 다 해봅니다.
평문 대신 salt를 섞은 SHA-256 해시로 넣어 두어 눈에 바로 띄지는 않는 정도입니다.

**진짜 접근 통제가 필요하면** Cloudflare Access(무료, 50명까지)를 사이트 앞에
걸면 이메일 인증이 붙습니다. 그 경우 PIN은 없애도 됩니다.

PIN을 바꾸려면 `tool/build_site.py`의 `PIN = "…"` 을 고치고 다시 빌드해서
루트 `index.html`을 교체한 뒤 push하면 됩니다.
